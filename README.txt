NEXLIX — مباريات اليوم (جدول يدوي) + باقات اشتراك
=====================================================

المحتويات
- index.html: واجهة NEXLIX كاملة (صفحة واحدة SPA).
- firebase.json / .firebaserc: إعداد Firebase Hosting (اختياري — النشر الحالي على GitHub Pages).

آخر التعديلات
--------------
1) جدول المباريات أصبح يدوياً ومباريات اليوم فقط.
2) صفحة اشتراك شهري / سنوي / 3 سنوات مرتبطة بأيقونة «اشتراك».
3) تصغير الشريط المتحرك إلى نصف حجمه السابق (58px ← 29px).

1) جدول المباريات اليدوي — اليوم فقط
-------------------------------------
- أُزيل الاتصال بـ TheSportsDB بالكامل: لا يوجد أي جلب تلقائي للبيانات.
- لا توجد مباريات الأمس ولا مباريات الغد؛ تُعرض مباريات اليوم فقط.
- التعديل من داخل index.html في مصفوفة MANUAL_MATCHES (ابحث عن «MANUAL_MATCHES»):

    { time:'18:00', home:'الأهلي', away:'الزمالك',
      leagueKey:'egypt', status:'upcoming',
      score:'2 - 1',               // اختياري
      venue:'استاد القاهرة الدولي',
      channel:'قناة رياضية' }

  time      : الموعد بنظام 24 ساعة بتوقيت القاهرة.
  home/away : اسم الفريق الأول والثاني.
  leagueKey : مفتاح البطولة من مصفوفة LEAGUES
              (egypt | england | spain | saudi | europe | italy).
  status    : upcoming (قادمة) | live (مباشر) | finished (انتهت).
  score     : النتيجة (اختياري — يظهر في المنتصف بدل الموعد).
  venue     : الملعب، channel: القناة الناقلة.

- إضافة/حذف بدون تعديل الكود: من صفحة «مباريات اليوم» يوجد زر
  «إضافة مباراة لليوم» (فريقان + الموعد + البطولة + الحالة + النتيجة + الملعب + القناة)
  وزر سلة لحذف مباراة من صفحة تفاصيل المباراة.
- ما يُضاف من داخل الموقع يُحفظ في localStorage ليوم واحد فقط،
  ويُصفَّر تلقائياً مع بداية يوم جديد (وكذلك عند منتصف الليل أثناء فتح الصفحة).
- لمسح جدول اليوم بالكامل: زر السلة بجانب «إضافة مباراة لليوم».
- أي مباراة في MANUAL_MATCHES لها حقل date صريح ولن تظهر إلا في ذلك التاريخ.

2) صفحة الاشتراك
-----------------
- تُفتح من: أيقونة «اشتراك» (التاج) في الشريط السفلي، وزر «اشترك الآن» في الرئيسية،
  وبطاقة «باقات الاشتراك» في الرئيسية والقائمة، وزر «اشترك لمشاهدة المباراة» في تفاصيل المباراة.
- الباقات: شهري 99 ج.م • سنوي 790 ج.م • 3 سنوات 1690 ج.م (مع متوسط شهري ونسبة التوفير).
- زر «اشترك الآن» يفتح نافذة إتمام الطلب مع رابط واتساب وبريد مُعبَّأين تلقائياً باسم الباقة وسعرها.
- عدّل الأسعار والمزايا من مصفوفة PLANS، ومقارنة الميزات من COMPARE_ROWS.
- عدّل بيانات التواصل من كائن CONFIG في أعلى السكربت:

    const CONFIG = {
      whatsapp: '201000000000',          // رقم واتساب بالصيغة الدولية بدون +
      email: 'contact@nexlix.example',   // بريد استقبال الطلبات
      currency: 'ج.م',
      timezone: 'Africa/Cairo'
    };

  مهم: استبدل رقم الواتساب والبريد ببياناتك الحقيقية قبل النشر.
- لا توجد بوابة دفع مربوطة؛ الصفحة تجمع الطلب فقط ولا تخصم أي مبلغ.

3) الشريط المتحرك
-----------------
- الارتفاع أصبح 29px بدل 58px (المتغير --ticker-h في :root) وحجم الخط 11–13px،
  لذا الهوامش العلوية للصفحات تتحدث تلقائياً معه.

تشغيل محلي
----------
- افتح index.html عبر خادم محلي (تجنب file:// لضمان عمل المشاركة/النسخ):
  python -m http.server 8080   ثم افتح http://localhost:8080

النشر
-----
- GitHub Pages: المصدر هو الفرع main وجذر المستودع (index.html فقط).
  أي دمج (merge) في main يحدّث الموقع تلقائياً بعد دقيقة تقريباً.
- Firebase Hosting (اختياري): firebase deploy --only hosting بعد ضبط .firebaserc.

ملاحظات
-------
- أقسام الأفلام والقنوات ما زالت بيانات تجريبية ولا تحتوي روابط بث.
- لا توجد بيانات مباريات آلية الآن: الجدول مسؤولية المحرر اليدوي.
