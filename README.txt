NEXLIX — مباريات اليوم (مجانية) + اشتراك الأفلام والقنوات
============================================================

المحتويات
- index.html: واجهة NEXLIX كاملة (صفحة واحدة SPA).
- firebase.json / .firebaserc: إعداد Firebase Hosting (اختياري — النشر الحالي على GitHub Pages).

ملخص النسخة الحالية
-------------------
1) صفحة المباريات مبسّطة: العنوان «مباريات اليوم» + سطر اسم اليوم والتاريخ وتوقيت القاهرة + قائمة المباريات. لا عدّاد، لا فلاتر، لا تعديل من الموقع.
2) المباريات مجانية للجميع — الاشتراك مخصّص للأفلام والقنوات.
3) الشريط المتحرك بارتفاع 29px (نصف الحجم السابق).

1) جدول المباريات — من الكود فقط
---------------------------------
- لا يمكن للزائر إضافة/تعديل/حذف أي مباراة: أُزيلت لوحة الإضافة وأزرار الحذف والمسح، وأُزيل التخزين المحلي (localStorage) بالكامل.
- المصدر الوحيد هو مصفوفة MANUAL_MATCHES في index.html (ابحث عن «MANUAL_MATCHES»):

    { time:'18:00', home:'الأهلي', away:'الزمالك',
      leagueKey:'egypt', status:'upcoming',
      score:'2 - 1',               // اختياري
      venue:'استاد القاهرة الدولي',
      channel:'قناة رياضية' }

  time      : الموعد بنظام 24 ساعة بتوقيت القاهرة.
  home/away : اسم الفريق الأول والثاني.
  leagueKey : مفتاح البطولة من مصفوفة LEAGUES
              (egypt | england | spain | saudi | europe | italy).
  status    : upcoming (قادمة) | live (مباشر) | finished (انتهت).
  score     : النتيجة (اختياري — تظهر في المنتصف بدل الموعد).
  venue / channel : الملعب والقناة الناقلة.

- تُعرض مباريات اليوم فقط: أي عنصر بدون حقل history/date يظهر كل يوم،
  وأي عنصر له date صريح يظهر في ذلك التاريخ فقط.
- تتحدّث الصفحة تلقائياً عند تغيّر اليوم (منتصف الليل بتوقيت القاهرة)،
  فلا تبقى مباريات الأمس ظاهرة.
- عند إضافة لوحة تحكم لاحقاً: يكفي أن تكتب المباريات في نفس بنية
  MANUAL_MATCHES أو أن تُمرّرها إلى matchesForToday().

2) الاشتراك = الأفلام والقنوات (المباريات مجانية)
--------------------------------------------------
- صفحة الاشتراك: «اشتراك الأفلام والقنوات» مع بطاقة خضراء أعلى الصفحة
  تؤكد أن المباريات مجانية ولا تحتاج اشتراكاً (وتنقل مباشرة لصفحة المباريات).
- الباقات: شهري 99 ج.م • سنوي 790 ج.م • 3 سنوات 1690 ج.م.
- الميزات تخص الأفلام والقنوات فقط (المكتبة، القنوات المباشرة، الجودة، الأجهزة).
- صفحتا الأفلام والقنوات تحملان شارة «بالاشتراك» وزر «اشترك لمشاهدة …».
- تفاصيل المباراة لا تحتوي أي دعوة للاشتراك، بل شارة «مشاهدة المباريات مجانية للجميع».
- زر «اشترك الآن» يفتح نافذة الطلب مع رابط واتساب وبريد مُعبَّأين باسم الباقة وسعرها.
- عدّل الأسعار/المزايا من PLANS، وجدول المقارنة من COMPARE_ROWS.
- عدّل بيانات التواصل من CONFIG أعلى السكربت:

    const CONFIG = {
      whatsapp: '201000000000',          // رقم واتساب بالصيغة الدولية بدون +
      email: 'contact@nexlix.example',   // بريد استقبال الطلبات
      currency: 'ج.م',
      timezone: 'Africa/Cairo'
    };

  مهم: استبدل رقم الواتساب والبريد ببياناتك الحقيقية قبل النشر.
- لا توجد بوابة دفع مربوطة؛ الصفحة تجمع الطلب فقط ولا تخصم أي مبلغ.

3) الشريط المتحرك
-----------------
- الارتفاع 29px بدل 58px (المتغير --ticker-h في :root)، والخط 11–13px،
  وهوامش الصفحات تتحدث تلقائياً معه.

الصفحة الرئيسية
---------------
- تُركت كما هي دون تغيير في التصميم أو الأقسام.

تشغيل محلي
----------
- python -m http.server 8080  ثم افتح http://localhost:8080
  (تجنّب file:// لضمان عمل النسخ/المشاركة).

النشر
-----
- GitHub Pages: المصدر فرع main وجذر المستودع (index.html).
  أي دمج في main يحدّث الموقع تلقائياً بعد دقيقة تقريباً.
- Firebase Hosting (اختياري): firebase deploy --only hosting بعد ضبط .firebaserc.

ملاحظات
-------
- أقسام الأفلام والقنوات ما زالت بيانات تجريبية ولا تحتوي روابط بث.
- لا توجد بيانات مباريات آلية: الجدول يُدار من الكود لحين بناء لوحة التحكم.
